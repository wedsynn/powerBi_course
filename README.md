## ✨ Features

- **Interactive Progress Tracking:** Check off topics as you master them with state persistence powered by `LocalStorage`.
- **Real-Time Search Engine:** Instantly filter through topics, keywords, and technical concepts.
- **Category Filtering:** Quickly toggle between views (Ingestion, Visuals, ETL, DAX, etc.).
- **Modern Dark Glassmorphism UI:** Built with **Tailwind CSS** for a clean, sleek, and responsive developer-friendly layout.
- **GitHub Pages Ready:** Easily deployable as a static site.

---

## 🚀 Roadmap Content Structure

The checklist is structured into **14 core modules** covering complete Power BI proficiencies:

1. **Import Data:** CSV, SQL Databases, Folders (Batch files).
2. **Dashboard Visualizations:** 
   - Bar Charts (Columns, Clustered, Stacked, 100% Stacked)
   - Line & Area Charts (+ Drill-down concepts)
   - Line & Columns, Common Charts (Pie, Donut)
   - Treemap, Scatter Plots, Maps (Filled Map, ArcGIS)
   - Uncommon Charts (Ribbon, Waterfall, Funnel)
   - Tables & Matrix + Conditional Formatting, Sparklines
   - Cards, Gauges, Multi-row Cards, KPI Cards
3. **Edit Interactions:** Cross-filtering configurations between dashboard visuals.
4. **Quick Measure:** Pre-built template formulas for rapid computation.
5. **Slicers & Controls:** Interactive filtering, Syncing Slicers across pages, Clear Slicer buttons.
6. **Buttons & Bookmarks:** Saving report states and custom UI loadouts.
7. **Section Panes:** Managing element grouping, layer orders, and hide/show visibility.
8. **Sketching & Wireframe:** Pre-planning layouts and visual hierarchy.
9. **Drill Through:** Dynamic detail pages capturing context from selected data points.
10. **Git / GitHub Integration:** Version control for `.pbip` workspace projects.
11. **Power Query (ETL Basics):** Data profiling, type changing, text cleaning, adding columns, reference vs. duplicate.
12. **Data Modeling:** Star Schema design, cardinality, and relationship filter directions.
13. **Advanced Power Query:** Table splitting, delimiter splitting, Pivot/Unpivot, Conditional columns, Append vs. Merge, Group By, Column by Example, Cluster columns.
14. **DAX (Data Analysis Expressions):** Calculated columns, custom tables, Implicit vs. Explicit measures, dynamic measures, and Field/Numeric parameters.
